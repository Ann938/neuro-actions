# Пикабу Нейро · быстрые действия в посте — прототип

Интерактивный прототип таб-бара Нейро в посте по макету Figma «Быстрые действия с постами через Нейро» (раздел «лента», 2373:246303; макет не менялся).
Статичный HTML/CSS/JS. Локально: `python -m http.server 3810`. Варианты: `#v1`…`#v4`.

1. Как в макете — одна кнопка → «думаю» → ответ → появляются остальные табы; табы «для прочитавших» внизу длинного поста.
2. Лента диалога — ответы копятся в одном чате, подсказки «Спросить ещё».
3. Боковая панель — разговор справа поверх сайдбара.
4. Компакт — табы в шапке карточки, скелетон, свёрнутый ответ, «Спросить своё».
